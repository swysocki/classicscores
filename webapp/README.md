# Classicscores Webapp (React)

This folder contains a minimal React app scaffolded for the Classicscores project. It uses Vite and Yarn.


Quick start (from repository root):

```powershell
cd webapp
# with Yarn
yarn install
yarn start

# or with npm
npm install
npm run start
```

Build:

```powershell
cd webapp
# with Yarn
yarn build

# or with npm
npm run build
```

Notes
- Static files in the repository root `static/` are available at `/static` when serving from the project root. You can copy them into `webapp/public` if you prefer bundling them with the app.
